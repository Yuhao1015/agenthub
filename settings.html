工作区域 交付物写进哪个文件夹 · 下次运行生效

当前工作区域
工作区域是 agent 写交付物的文件夹。保存后下一次 运行开始，产出会直接写进你选的文件夹（正在跑的运行不受影响， 旧运行的交付物留在原目录，不会自动搬过去）。文件夹必须在数据目录之外， 避免跟运行记录混在一起。macOS 点「选择文件夹…」会弹系统选择器；其它 系统请手动粘贴路径。

员工入职清单 本机探测 · 零花费

工具权限 只收紧 · 仅 claude_code · 下次 run 生效

只能去掉工具、不能加回矩阵里没有的；全不勾会自动保留 Read（空字符串实测不会限制任何工具，Read 是验证过的最小集）。改动写入 本地 config.yaml 的 matrix_patch，下一次运行生效；codebuddy/dsh/ openrouter 不读这个字段。

真实体检 每台机器跑一次 · 每个 agent 花几个 token

体检会用真实调用验证每个 agent 对当前账号是否真的可用——存在性探测查不出"装了、登录了、但这个模型对这个账号不可用"（CLAUDE.md §4 的真实事故）。

护栏金额 你自己定 · 只对 openrouter 按量付费生效

claude_code 订阅额度与 codebuddy 积分消耗不计入此护栏；dsh 暂无用量上报，也不计入。

密钥 只写本机文件 · 永不联网 · 不回显

claude / workbuddy 走各家 CLI 登录（claude login / WorkBuddy 登录），不在这里配。

零成本演示 不需要任何 key

30 秒内看到办公室动起来——第一次用的朋友先点这个。

定时目标 best-effort · 仅在本应用开着时触发

只在 Agent Hub 开着的时候才会触发——不是系统级 cron，应用没开等于这次错过，不会补跑。触发时直接用保存的目标文本开工，没有经理追问澄清的机会，目标文本要写清楚、不依赖临场补充信息。

备份数据 普通文件 · 用你的系统工具复制即可

当前项目数据
这个项目的全部运行记录、配置——用 Finder / 资源管理器 / rsync / Time Machine 直接复制这个文件夹就是完整备份，复制回原路径就是 完整恢复，都是普通文件。此路径不含凭证。
⚠️ 凭证文件：—— 存的是你配置过的真实 API key，明文保存，权限 0600（只有你的账号能读）。 默认不要把它跟上面那个文件夹一起备份——一旦拷到 U 盘、 发邮件、同步进网盘，就丢失了 0600 权限的保护，key 明文就在别人可能 看到的地方了。只有你确实需要把密钥也带到新电脑时，才手动单独处理这 一个文件，且用加密方式传输（比如加密压缩包，或者到了新机器直接在设置 页里重新填一遍 key——重新配置往往比传输这个文件更安全）。
整个数据目录
整个数据目录 = 全部项目 + 凭证文件（会连密钥一起复制）。 恢复：把备份放回同一位置即可；放回自定义位置要用命令行 python3 serve.py --data-dir <你的路径> 启动， 双击启动器目前只认默认位置。
