工作区域 交付物写进哪个文件夹 · 下次运行生效

当前工作区域
工作区域是 agent 写交付物的文件夹。保存后下一次 运行开始，产出会直接写进你选的文件夹（正在跑的运行不受影响， 旧运行的交付物留在原目录，不会自动搬过去）。文件夹必须在数据目录之外， 避免跟运行记录混在一起。Windows 和 macOS 点「选择文件夹…」会弹系统选择器，也可以手动粘贴绝对路径。

API 连接 自带模型与密钥 · 按需接入

添加自己的服务，选择 OpenAI 兼容（Chat Completions）、Anthropic（Messages）或 OpenRouter 格式。每个连接单独管理模型与密钥。

密钥只保存在本机，不回显。保存不会请求模型；测试连接需单独确认，可能收费。本机 Agent 使用各自已登录的账号。

定时目标 best-effort · 仅在本应用开着时触发

只在 Agent Hub 开着的时候才会触发——不是系统级 cron，应用没开等于这次错过，不会补跑。触发时直接用保存的目标文本开工，没有经理追问澄清的机会，目标文本要写清楚、不依赖临场补充信息。

备份数据 普通文件 · 用你的系统工具复制即可

当前项目数据
这个项目的全部运行记录、配置——用 Finder / 资源管理器 / rsync / Time Machine 直接复制这个文件夹就是完整备份，复制回原路径就是 完整恢复，都是普通文件。此路径不含凭证。
⚠️ 凭证文件：—— 存的是你配置过的真实 API key，明文保存，权限 0600（只有你的账号能读）。 默认不要把它跟上面那个文件夹一起备份——一旦拷到 U 盘、 发邮件、同步进网盘，就丢失了 0600 权限的保护，key 明文就在别人可能 看到的地方了。只有你确实需要把密钥也带到新电脑时，才手动单独处理这 一个文件，且用加密方式传输（比如加密压缩包，或者到了新机器直接在设置 页里重新填一遍 key——重新配置往往比传输这个文件更安全）。
整个数据目录
整个数据目录 = 全部项目 + 凭证文件（会连密钥一起复制）。 恢复：把备份放回同一位置即可；放回自定义位置要用命令行 python3 serve.py --data-dir <你的路径> 启动， 双击启动器目前只认默认位置。
